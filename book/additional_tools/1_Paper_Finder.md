# 🔍 Paper-Finder

GUI-based tool for discovering and searching papers across multiple databases.

## Overview

Paper-Finder is a graphical user interface (GUI) tool designed to simplify the process of searching for academic papers across multiple databases. Unlike command-line tools, Paper-Finder provides an intuitive visual interface that makes literature search accessible to researchers of all technical backgrounds.

### Main Capabilities

- **Multi-Database Search**: Query multiple academic databases simultaneously
- **User-Friendly Interface**: No command-line knowledge required
- **Visual Search Builder**: Construct complex queries with visual tools
- **Real-Time Results**: See search results as they come in
- **Export Options**: Save results in various formats
